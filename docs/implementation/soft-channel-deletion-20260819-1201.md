# Soft channel deletion

Replaced destructive channel deletion with archival so stored snapshots remain intact. Added a second dated closure path that records a zero balance, retains earlier history in charts, and hides the channel from the selected date onward. The channel editor now exposes both actions through icon-only, two-stage controls with an editable date for closure and no restoration control. Chart details identify the closing snapshot by crossing out the channel name, including closures that produce no numeric change.
